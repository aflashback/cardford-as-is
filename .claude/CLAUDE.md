# Beatmark

## Sub-agents and workflow agents
- Very complex or long-running tasks: Opus 5.5 effort xhigh.
- Complex, focused tasks: Opus 5.5, effort high.
- Straightforward tasks (finding info, searching Notion or the web, summarizing): Sonnet 5.5, with effort matched to how complex the task is.

## Superpowers rules
- Tests cover functional behavior only. Skip non-functional requirements and architecture principles unless the task asks for them.
- Keep plan verification short. Point to existing plans, architecture, brand, guides and source files instead of restating them.
- The repos in this folder are the source of truth. Read them first, and use Notion or other sources only when the repos don't have the answer.
