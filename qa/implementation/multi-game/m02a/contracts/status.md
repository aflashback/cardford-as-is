Coverage includes all 99 named shape witnesses, closure/unknown nested private fields, optional/null/absent fields, integers/binary64 rounding, union tags, array uniqueness and size, conditional schemas, mutually exclusive fields, string/ID bounds, Unicode scalar length, date-text preservation, duplicates and lone surrogates.

- **10** canonical vectors compare exact bytes and SHA-256 with the original TS kernel/gate functions and the actual repository `idempotent` function, using a private query stub to capture the command digest without a DB connection. They include current command/Hearts packet/Spades packet/decision-envelope shapes, numeric object key enumeration, Unicode ordering differences, binary64 boundaries plus **256** deterministic random finite binary64 values, and all **3,844** two-character ASCII alphanumeric keys.

- Raw-parser checks reject malformed/trailing/multiple-root JSON, duplicates, invalid UTF-8, lone surrogate escapes, number overflow, documents over 16 MiB and nesting over 128. Remote schema resources and unreviewed patterns fail closed.

`manifest.json` records exact source hashes, registry/binding inventory, actual runtime/locale and deliberate Ajv-versus-byte-boundary differences. `implementation-manifest.json` records the delivered implementation/document hashes. `validation-fixtures.json` and `semantics-fixtures.json` are generated from the existing TS validators/functions; Go does not generate its own expected results. Regeneration is explicit and `--check` detects drift.

## Deliberate limitations

- Duplicate properties and unpaired UTF-16 strings accepted by JS parsing are rejected by the Go byte boundary. These four cases are named in the manifest. Unsupported historical representations require an original compatible reader or separately versioned migration.
- Legacy canonical helpers support ASCII alphanumeric object keys; punctuation/Unicode keys fail explicitly. UTF-16 canonicalization is a separately named existing algorithm and must not replace a legacy digest. No universal historical-collation parity is claimed.
- Date fields retain the existing string-schema semantics. A nonempty invalid date can still pass where the source imposes no date format. Domain integer safety remains separate from an unbounded public integer schema.
- Public shape witnesses are not reachable-game-state evidence. Opaque union bindings validate complete values but do not provide generated field accessors for every variant. Private platform/history records, the legacy constraint sampler port, full strategy parity, full frontend replacement journeys and hosted/provider/human checks are outside this package's evidence.
