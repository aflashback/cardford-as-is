# CardFord Rally

The owner has reviewed and approved Rally, including the design system and PNG/SVG coach artwork. The design phase is closed. This folder contains only the selected design package and its local preview server.

- [Approved package and guide](rally/README.md)
- [Open Rally](http://127.0.0.1:4188/rally/approved/#play)
- [Design system](http://127.0.0.1:4188/rally/design-system/)
- [Sticker assets](rally/assets/stickers/README.md)

From the repository root, run `node design/serve.mjs` and open <http://127.0.0.1:4188/rally/>. The former `/studio/` review address redirects to the approved Rally mock.

Unselected designs, competition pages, duplicate working files and obsolete competition reports have been removed. The Rally package retains its own source, assets, licenses and relevant verification. The internal `studio` styling key belongs to Rally; it is not another design folder.

No production game UI or backend implementation is included in this design cleanup.
