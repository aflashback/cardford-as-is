## Audit and contract freeze

The accepted M04C/D API is deliberately narrower than the current client. Missing prerequisites include legal candidates and result presentation, durable preferences/help statistics, progressive advice, original replay, isolated possible continuations and local account/family/export behavior. A URL replacement cannot supply those capabilities.

New closed `platform-service`, `platform-account` and `platform-review` public fragments extend the generated `local-service` bundle. Original V1 schemas and M04C/D route contracts remain unchanged. `PlatformSessionView` wraps the registered module view, immutable selector/pins/competition/controllers, human actor packet, game-owned presentation, authoritative access, preferences and committed assistance statistics. The existing `GameView` is an explicit current-game presentation adapter for the preserved UI, not the canonical module model for future games.

Account responses distinguish configured offers from named-plan local fixtures. Fixture billing changes must affect server permissions; configured offers cannot inherit fixture grants. Review reads original stored outputs and actual accepted human actions. Possible continuations use only the source human observation and a synthetic feasible world; actual concealed hands never become a planning input.
