# Approved Rally Coach artwork

The five PNG files here are unchanged copies of the owner-approved masters in
`design/rally/assets/stickers/png/`:

- `regular-waiting-v2.png`
- `regular-whistle-v3.png`
- `regular-thinking-v2.png`
- `regular-explaining-v2.png`
- `regular-reading-v8.png`

The artwork was generated and revised using the built-in image tool, then selected
by the owner. `SOURCE-ARTWORK.md` retains the original prompts and provenance.
Historical design paths in that record identify the source work; they are not
runtime dependencies. Do not recolor, redraw or replace these masters.

The accompanying `licenses/vtracer-MIT.txt` is the software notice shipped with
the approved design asset package. It applies to the tracing tool used for the
separate SVG derivatives, not to these PNG images. This copy does not assign a
new third-party or open-source license to the generated artwork.
